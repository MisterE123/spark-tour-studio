Radix 0.0.1 — growing sort capacity

This standalone page uses synthetic data, pinned Radix and Three only. It first warms shaders at the smallest count, then increases the count on one persistent sorter. It replays the same counts after maximum capacity is reached. That second pass is the fixed-capacity control. There are no SOG files, network streaming, Studio code, physics or XR.
